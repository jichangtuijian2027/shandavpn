## 闪达加速器值得买吗？

从目前这次体验来看，我对闪达的第一印象还是不错的。

**最大的特点不是套餐有多便宜，而是目前用户规模比较小，线路压力相对较低。**

我自己使用的是1小时免费试用，实际测试下来速度确实比较快，日常浏览网页和视频播放都比较流畅。

但是这里还是要保持一点理性。

目前群里活跃人数大约只有200人，用户数量比较少，很可能也是现在速度表现比较好的原因之一。随着以后用户数量增加，线路负载、带宽资源以及服务器压力都有可能发生变化。

所以现在测试出来的速度，并不能直接代表几个月之后的表现。

说得简单一点：

**现在跑得快是一回事，用户多了以后还能不能跑得快，是另外一回事。**

因此，如果只是想找一个目前用户量不大、速度表现不错的服务，可以先利用1小时免费试用测试一下。

如果测试结果符合自己的网络环境，再考虑购买7天、30天或者90天套餐，会比直接购买长期套餐更加稳妥。
